Deliverables (Submission Pack)

This folder is a submission-oriented index of what each challenge asked for,
where it lives in the app, and how to demonstrate it quickly.

Quick links (local)
- App home: http://localhost:3000
- All challenges: http://localhost:3000/challenges
- Tools: http://localhost:3000/tools
- Creative system proof:
  - Generator: http://localhost:3000/tools/creative-generator
  - Library (approve/reject): http://localhost:3000/tools/creative-library
  - Media step (SVG + OpenRouter image): http://localhost:3000/tools/media-studio
  - Audit (required set): http://localhost:3000/tools/creative-audit
  - Diagram (AI vs human): http://localhost:3000/tools/creative-diagram
- Dashboard (events + waitlist): http://localhost:3000/dashboard
- API page: http://localhost:3000/api

Contents
- deliverables/CHECKLIST.txt — mapping from prompt → implementation
- deliverables/RUNBOOK.txt — what to click/record to show E2E flows
- deliverables/sample_inputs/ — ready-to-paste JSON payloads for key endpoints
- deliverables/sample_outputs/ — deterministic outputs generated locally (no keys)
- deliverables/screen_recordings/ — drop your recorded clips here (videos are gitignored)
